# E026 — Fan-Out Category and Citation Rate: Frozen Query Set

## Files

- `e026_query_taxonomy.csv` — 150 frozen queries (1 header + 150 rows). Columns: query_id, target_page, category, query_text, word_count. Frozen 2026-06-08, published with the pre-registration post before the measurement window opened.

## Design

150 queries across 10 fan-out intent categories (Pete Meyers, BrightonSEO April 2026), 3 queries per category per page, 5 target pages, 5 consecutive days on Perplexity sonar-pro = 750 measurements.

**Target pages (5):** /geo-stack/, /extractability/, /retrieval-probability/, /entity-reinforcement/, /structural-authority/

**Categories (10):** Anticipate, Attribute, Compare, Entity, Factual, Follow-up, Insight, Semantic, Transact, Tutorial

**Measurement window:** 10–14 June 2026 (5 days). Platform: Perplexity sonar-pro via DataForSEO AI Optimization API.

**Noise floor reference:** E016 22.0pp threshold (DOI: 10.5281/zenodo.19869156).
