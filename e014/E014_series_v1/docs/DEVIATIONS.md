# E014 Deviation Log

1. Not pre-registered. The study design, query set and coding rule were fixed at the start but never deposited before data collection.

2. Baseline and M1 raw data lost. Row-level files were never consolidated and could not be recovered (confirmed 10 Sep 2026). Figures survive in the contemporaneous write-up only.

3. M2 denominator. M2 used 70 reads rather than 50.

4. Instrument change at M5. From M5, Perplexity reads used a fresh Chrome incognito profile per query and ChatGPT reads were forced to search. Both corrected known under-counting, and both landed in the same month as the M4 to M5 jump (6% to 48%). The jump is therefore confounded and not attributed to accumulation. An audit of M2 and M3 raw data found citation was query-specific rather than session-position-specific, which argues against a pure degraded-read artefact but does not rule out a Perplexity platform change between June and August 2026.

5. M5 Tier 2 query strings. The M5 capture sheet carried reconstructed query strings that had not been checked against the frozen set; they were the strings actually fired (confirmed 28 Sep 2026 from the run transcript). Q1 was shortened ("What is GEO?"), Q4, Q7 and Q10 were different questions, and Q3 differed in capitalisation only. The M5 CSV is deposited unchanged. The M5 Tier 2 row is excluded from the longitudinal series; M5 Tier 1 is retained with a capitalisation note on Q3.

6. Late measurements. M5 ran 2 Aug (due 28 Jul). M6 ran 9 Sep (due 28 Aug). M7 ran 19 days after M6. Recorded as dated intervals.

7. Single reads on two engines. ChatGPT and Google AI Overviews were read once per query per month, below the five-render minimum The GEO Lab applies to citation claims. Their per-engine rates are directional. Perplexity (3 iterations) is the only leg with within-month repetition.

8. Control entity run once. The M6 control-entity probe was not repeated at M7. The control argument rests on 5 reads from M6.

9. M7 discarded reads. Three unprimed ChatGPT reads (Q1, Q2, Q3) answered from model memory with no sources and were discarded before the forced-search reads were collected.

10. M7 Q9 confirmation re-run. After Perplexity iteration 2 resolved Q9 to an unrelated operating system, the query was re-run once in the same slot and returned the framework. The recorded iteration 2 read (X) stands; the re-run is noted, not substituted.

11. M7 ChatGPT Q5. Source chips were labelled "The GEO Lab" but the full URL was not captured. Coded C on the chip label.

12. M7 raw answer text. See raw/m7/.
